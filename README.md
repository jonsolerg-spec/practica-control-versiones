# practica-control-versiones
Práctica de control de versiones con Git y GitHub
Autor: Jonathan Soler Guevara
## Descripción del proyecto

Este repositorio fue creado como parte de la Guía de Laboratorio No. 6 de la asignatura Estándares y Métricas de Calidad de Software de la Universidad Manuela Beltrán.

El objetivo de esta práctica es aprender a utilizar Git y GitHub para gestionar versiones de un proyecto, crear ramas, realizar commits y trabajar de manera colaborativa.
